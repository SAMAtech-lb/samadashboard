SAMA Admin

Sign in with a GitHub access token that can edit the samadashboard repository.

How do I get a token?
  1. Open GitHub's new token page.
  2. Set Resource owner to SAMAtech-lb.
  3. Under Repository access, choose Only select repositories and pick samadashboard.
  4. Under Permissions, set Contents to Read and write.
  5. Generate the token and paste it above. Treat it like a password.
