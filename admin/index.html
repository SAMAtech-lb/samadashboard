SAMA Admin

Sign in with a GitHub access token that can edit the samadashboard repository. Afterwards you can set an email and password in Login settings.

How do I get a token?
  1. Open GitHub's new token page.
  2. Set Resource owner to SAMAtech-lb.
  3. Under Repository access, choose Only select repositories and pick samadashboard.
  4. Under Permissions, set Contents to Read and write.
  5. Generate the token and paste it above. Treat it like a password.

Login settings

Set the email and password for signing in. They are never saved or sent anywhere. They only unlock your GitHub token, which is stored encrypted on this site.

Use a long password you don't use anywhere else, at least 14 characters. The encrypted file is public, so a weak password could be guessed. If you forget it, sign in with a GitHub token and set a new one.
